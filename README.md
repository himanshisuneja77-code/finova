# 💰 Finova – Smart Finance Tracker

Finova is a modern and user-friendly **finance tracking web application** that helps users manage their income, expenses, and savings goals efficiently. It provides real-time insights, analytics, and budgeting features — all in one place.

## 🚀 Features

### 📊 Core Features

* ✅ Add Income & Expense Transactions
* ✅ Real-time Balance Calculation
* ✅ Search & Filter Transactions
* ✅ Edit & Delete Transactions

### 📈 Analytics

* 📊 Bar Chart (Income vs Expense)
* 🥧 Pie Chart (Category-wise Expenses)
* 📥 Export Data as CSV

### 🎯 Goals Management

* Set financial goals
* Track savings progress
* Add money to goals
* Edit/Delete goals

### 💡 Advanced Features

* 🌙 Dark Mode Toggle
* 💰 Monthly Budget with Warning Alert
* 🔁 Recurring Transactions
* 🌍 Multi-Currency Support (INR, USD, EUR, etc.)
* 🏷️ Custom Categories
* 💾 Local Storage Data Persistence


## 🛠️ Tech Stack

* **Frontend:** HTML, Tailwind CSS
* **JavaScript Framework:** Alpine.js
* **Charts:** Chart.js
* **Storage:** LocalStorage (Browser-based)


## 📸 Screens

* Landing Page
* Authentication (Login / Signup)
* Dashboard
* Add Transactions
* Analytics
* Goals Tracker


## 🧑‍💻 How to Use

1. Open the project in your browser
2. Click **Start Free 🚀**
3. Signup or Login
4. Start adding transactions
5. Track analytics and manage goals
